Kusanagi is an observability and self-healing platform for Kubernetes, inspired by the Ghost in the Shell universe. Our mission is to provide a unified cybernetic interface to monitor and manage your K8s infrastructure with total efficiency and elegance.

🌐 Cilium Network

Kusanagi integrates with Cilium for advanced network observability and security monitoring via Hubble.

🔍 Network Flows

Real-time visualization of network traffic between pods with Hubble flows.

GET /api/cilium/flows

📊 Flow Matrix

Aggregated view of all network connections between services.

GET /api/cilium/matrix

📈 Bandwidth Metrics

Per-service bandwidth consumption and connection counts.

GET /api/cilium/metrics

⚠️ Anomaly Detection

Automatic detection of unusual network patterns.

GET /api/cilium/anomalies

🔧 Cilium Status

Health and version information of Cilium agents.

GET /api/cilium/status
